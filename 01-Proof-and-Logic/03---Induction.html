Induction

Mathematical Induction is the process of proving a statement by showing it is true for the base case, then showing that if it is true for some integer , then it is true for ; it then follows it must be true for all integers greater than the base case.

The steps are:

  1. Show it is true for the base case, usually (but not always) .
  2. Assume there exists some integer , where the statement holds.
  3. Show that the statement holds for
  4. Conclude that the statement is true for all integers, greater or equal to the base case, usually (but not always)
