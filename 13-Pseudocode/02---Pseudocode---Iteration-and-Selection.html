02 Pseudocode Iteration and Selection

Pseudocode — Iteration and Selection

Pseudocode is a way of writing algorithms without using a programming language; instead it uses Structured English. Below are the VCAA conventions:

  • Write only one statement per line.
  • is used for assigning values to variables.
  • is used for checking equality between two values.
  • Indentation is used to show the hierarchy of processes within an algorithm.
  • Nested structures must end with explicit keywords: end if, end while, end for.
  • Iteration is handled via for or while loops; repeat until can also be used.
  • Selection is handled via if statements.

For Loops

A for loop repeats a fixed number of times. The syntax is:

for variable from start to end
    instructions
end for

Example 2.1
Print the first 8 square numbers.

for n from 1 to 8
    print n^2
end for

Output: 1, 4, 9, 16, 25, 36, 49, 64

While Loops

A while loop repeats while a condition is true. The syntax is:

while condition
    instructions
end while

Example 2.3
Print powers of 3 less than 1000.

n ← 0
value ← 1
while value < 1000
    print value
    n ← n + 1
    value ← 3^n
end while

Output: 1, 3, 9, 27, 81, 243, 729

Selection (If Statements)

Selection allows an algorithm to make decisions and follow different paths. The syntax is:

if condition then
    instructions
else
    alternative instructions
end if

Example 2.5
Determine if a number is positive or negative.

input x
if x > 0 then
    print "positive"
else
    print "negative or zero"
end if

Solution

For multiple conditions, use else if:

Example 2.6
Find the maximum of two numbers.

input a, b
if a > b then
    print a
else if b > a then
    print b
else
    print "equal"
end if
